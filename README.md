# open-data-lab

オープンデータを集めて、特定の分野に絞って検索・可視化するサイトを作る実験場です。

## プロジェクト

| ディレクトリ | 内容 | 状態 |
|---|---|---|
| [`subsidy-finder/`](subsidy-finder/) | **北海道 補助金ファインダー**：北海道の事業者が使える補助金・助成金を、Jグランツ（国）と北海道庁の公開情報から毎日集めて検索・可視化 | 試作版 |
| `research-funding/` | **研究費マップ**：科研費データベース（KAKEN）から、分野別・機関別の研究費の流れを可視化 | 予定 |

## 共通の方針

- **静的サイト＋定期バッチ**：GitHub Actions で定期的にデータを取得し、静的サイトとして GitHub Pages に公開する。サーバーを持たない。
- **データ源の利用条件を守る**：出典を各ページに明記する。転載・再利用に許諾が必要なデータ源は、許諾を得るまで使わない。
- **取得したデータはリポジトリに残す**：どのデータでサイトを作ったかを後から追えるようにする。
