# open-data-lab

オープンデータを集めて、特定の分野に絞って検索・可視化するサイトを作る実験場です。

公開先：https://cum38898.github.io/open-data-lab/

## プロジェクト

| ディレクトリ | 内容 | 公開パス |
|---|---|---|
| [`subsidy-finder/`](subsidy-finder/) | **北海道 補助金ファインダー**：北海道の事業者が使える補助金・助成金を、Jグランツ（国）と北海道庁の公開情報から毎日集めて検索・可視化 | `/subsidy-finder/` |
| [`diet-tracker/`](diet-tracker/) | **国会議論トラッカー**：テーマごとの国会での発言数の推移と、新しい法律の審議経過を、国会会議録から毎日集計 | `/diet-tracker/` |

トップページ（プロジェクト一覧）は [`pages/index.html`](pages/index.html) です。

## 共通の方針

- **静的サイト＋定期バッチ**：GitHub Actions で毎日データを取得し、静的サイトとして GitHub Pages に公開する。サーバーを持たない。
- **データ源の利用条件を守る**：出典を各ページに明記する。転載・再利用に許諾が必要なデータ源は、許諾を得るまで使わない（検討して見送ったデータ源は各プロジェクトの README に記載）。
- **取得したデータはリポジトリに残す**：どのデータでサイトを作ったかを後から追えるようにする。

## 公開の仕組み

`.github/workflows/site.yml` がすべてのプロジェクトをまとめて扱います。

- **毎日 05:17（日本時間）と手動実行**：各プロジェクトのデータを取得 → コミット → 全サイトをビルド → GitHub Pages に公開
- **main への push**：コミット済みのデータでビルドして公開
- **プルリクエスト**：テストとビルドだけ

初回だけ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にしてください。
