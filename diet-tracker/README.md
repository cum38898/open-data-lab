# 国会議論トラッカー

国会で、どんなテーマがどれだけ議論されているかを、国会会議録から毎日集計して見せる静的サイトです。

- **テーマ**：物価高・賃上げ・生成AI・半導体・北海道など。テーマごとに、検索語を含む発言の数を月ごとに集計し（2023年1月以降）、会派・立場別、会議別の内訳と、最近の発言の抜粋（会議録へのリンク付き）を表示します。
- **新しい法律**：2025年以降に公布された新しい法律を e-Gov 法令検索から集め、題名を含む会議を会議録で探して、いつ・どの会議で審議されたかをたどれるようにします。

## データの出どころと利用条件

| データ源 | 使い方 | 利用条件 |
|---|---|---|
| [国会会議録検索システム 検索用API](https://kokkai.ndl.go.jp/api.html)（国立国会図書館） | テーマの検索語を含む発言を検索して数える。法律の題名を含む会議を探す | 登録不要。発言の著作権は各発言者にあり、原則は許諾が必要。ただし「引用」「政治上の演説等の利用」「電子計算機による情報解析」などは許諾なく利用できる（API 仕様「利用条件・免責事項」） |
| [e-Gov 法令API v2](https://laws.e-gov.go.jp/api/2/)（デジタル庁） | 2025年以降に公布された新しい法律の一覧 | 法令は著作権の対象外（著作権法13条） |

このため、このサイトは次の範囲でだけ会議録を使います。

- **数える**：発言の件数を集計する（情報解析）。
- **短く抜き出してリンクする**：検索結果として、検索語の前後だけ（120字ほど）を抜き出し、会議録の該当箇所へリンクする。抜粋はテーマごとに新しい40件分だけ保存する。
- **しないこと**：発言の全文は保存も掲載もしない。特定の議員の発言だけを集めて並べるページは作らない（著作権法40条1項の「同一の著作者のものを編集して利用する場合」に当たらないようにするため）。

API へのアクセスは、国立国会図書館の求めに従い、同時に送らず、前のリクエストが終わってから3秒あけています（`etl/common.py` の `Polite`）。

## 構成

```
diet-tracker/
├── etl/                  # Python（標準ライブラリのみ）
│   ├── topics.json       # 集計するテーマと検索語（ここを編集すればテーマを増やせる）
│   ├── kokkai.py         # テーマごとの発言を取得（初回は全件、以降は直近60日分を取り直す）
│   ├── laws.py           # 新しい法律の一覧と、審議した会議
│   ├── fetch.py          # 入口
│   └── tests/
├── data/
│   ├── topics/<id>.json  # テーマごとの発言の一覧（ID・日付・院・会議・発言者・会派・肩書き）と最近の抜粋
│   └── laws.json
└── site/                 # Astro の静的サイト
```

### テーマを増やす

`etl/topics.json` にテーマを足して `python -m etl.fetch --topics <id>` を実行します。`queries` に複数の語を書くと、どれかを含む発言を重複なく数えます。1つの語の中で半角スペースで区切ると AND 検索になります。検索語を変えると、そのテーマは次の取得で全件を取り直します。

## 手元で動かす

```sh
cd diet-tracker
python -m etl.fetch                  # 初回は全テーマで20〜30分ほど
python -m etl.fetch --topics ainu    # 一部のテーマだけ
python -m unittest discover -s etl/tests -t .

cd site
npm ci
BASE_PATH=/ npm run dev
npm test
```

## 注意点

- 会議録は開会から公開までに日数がかかるため、直近1か月ほどの件数は少なめに出ます（グラフでは斜線）。
- 検索は部分一致です。「原発」は「原発事故」も「原発ゼロ」も含みます。
- 会派の正式名称は時期や院で異なるため、主な政党名にまとめています（`site/src/lib/groups.ts`）。規則にない会派は正式名称の先頭部分をそのまま表示します。
- 法律の審議経過は題名の部分一致で探しているので、法律案のときと題名が違う場合などは見つかりません。一部を改正する法律は含みません。
